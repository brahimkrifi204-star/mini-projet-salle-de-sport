# FitZone — site d’une salle de sport

Mini-projet Dev. Web côté client — TI1, A.U. 2026-2027.

- **Auteur(s)** : Brahim Krifi
- **Technologies** : HTML5 sémantique, CSS3 (Flexbox, Grid, variables, media queries mobile-first), JavaScript (DOM, événements)
- **Ouvrir le site** : ouvrir le dossier dans VS Code, puis clic droit sur `index.html` → Open with Live Server

## Interactions JavaScript
1. Menu burger (mobile)
2. Mode clair / sombre mémorisé
3. Compteurs animés
4. Filtre des activités par catégorie
5. Calculateur de prix d’abonnement
6. Validation du formulaire de contact
